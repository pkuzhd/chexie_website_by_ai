## 3. 文档规范

### 3.1 命名规范

- API文档文件命名格式：`功能模块_api.md`（如：`auth_api.md`、`post_api.md`）
- 文件名使用小写字母和下划线，避免空格和特殊字符

### 3.2 内容规范

每个API文档应包含以下内容：
1. 文档概述
2. 认证方式（如适用）
3. API接口列表（表格形式）
4. 接口详细说明（包括请求信息、参数、响应示例等）
5. 错误代码说明
6. 安全说明
7. 版本信息

### 3.3 更新规范

- API文档应与代码同步更新
- 重大变更应在文档中记录变更历史
- 更新时间和版本号应及时更新

## 4. 使用指南

1. 根据功能模块查找对应的API文档
2. 在文档中查看接口详细说明
3. 遵循文档中的请求格式和参数要求调用API
4. 注意认证方式和安全说明

## 5. 联系方式

如有API相关问题或建议，请联系项目开发团队。
