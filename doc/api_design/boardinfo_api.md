# 板块信息API规范

## 1. 文档概述

本文档描述了论坛项目后端的板块信息接口规范，包括获取所有板块信息和获取单个板块信息功能。

## 2. 认证方式

- **认证类型**：无
- **访问权限**：公开接口，无需登录即可访问

## 3. API接口列表

| 接口URL | 请求方法 | 功能描述 | 是否需要认证 |
|---------|----------|----------|--------------|
| `/api/boardinfo` | GET | 获取所有板块信息 | 否 |
| `/api/boardinfo/:bid` | GET | 获取单个板块信息 | 否 |

## 4. 接口详细说明

### 4.2 获取单个板块信息接口

#### 请求信息
- **URL**: `/api/boardinfo/:bid`
- **方法**: `GET`

#### 请求参数

| 参数名 | 类型 | 必选 | 描述 |
|--------|------|------|------|
| bid | Number | 是 | 板块ID |

#### 响应信息

##### 成功响应 (200 OK)

```json
{
  "message": "获取板块信息成功",
  "data": {
    "bid": 1,
    "name": "act",
    "bbstitle": "车协工作区",
    "hide": 0,
    "m1": "沧海月明",
    "m2": "烟景",
    "m3": "水溶C100",
    "m4": "",
    "need": 0
  }
}
```

##### 失败响应

- **404 Not Found**：板块不存在
  ```json
  {
    "message": "板块不存在"
  }
  ```

- **500 Internal Server Error**：服务器错误
  ```json
  {
    "message": "服务器错误"
  }
  ```

## 5. 错误代码说明

| 状态码 | 描述 |
|--------|------|
| 200 | 请求成功 |
| 404 | 板块不存在 |
| 500 | 服务器内部错误 |
