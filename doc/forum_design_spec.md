# 论坛系统设计说明书

## 1. 项目概述
本项目旨在构建一个功能完善的在线论坛系统，为用户提供交流、分享和互动的平台。系统包含用户端和管理端，支持PC端和移动端访问。

## 2. 核心功能模块

### 2.1 用户模块
- **注册/登录**：支持用户名/邮箱注册，MD5加密存储密码，JWT认证。
- **个人中心**：
  - 查看/修改个人信息（头像、昵称、简介）。
  - 查看我的发布（帖子、回复）。
  - 查看我的收藏/点赞。
  - 密码修改。
- **用户权限**：普通用户、版主、管理员、超级管理员（论坛上帝）。

### 2.2 内容模块 (帖子)
- **发帖**：支持富文本编辑器，上传图片/文件，选择分类/标签。
- **浏览**：
  - 首页帖子列表（按时间、热度、分类筛选）。
  - 帖子详情页（内容展示、楼主信息）。
- **互动**：
  - 回复/评论（支持楼中楼）。
  - 点赞/踩。
  - 收藏帖子。
- **管理**：
  - 作者可删除/编辑自己的帖子。
  - 管理员可置顶、加精、删除任何帖子。

### 2.3 搜索与发现
- 关键词搜索（标题、内容）。
- 热门话题/标签推荐。

### 2.4 后台管理
- **普通管理员权限**：
  - 用户管理（权限调整，可设置普通用户和版主）。
  - 数据统计（日活、发帖量等）。
- **超级管理员（论坛上帝）权限**：
  - 包含所有普通管理员权限。
  - 修改管理员和版主权限（可提升或降级管理员和版主）。

## 3. 界面设计 (UI/UX)

本部分详细描述各个核心页面的布局与交互元素。

### 3.1 首页 (Home Page)
**布局结构**：顶部导航栏 + 左右分栏布局
- **顶部导航栏**：
  - 左侧：Logo、首页链接、版块分类下拉菜单。
  - 中间：全局搜索框。
  - 右侧：
    - 未登录：[登录] [注册] 按钮。
    - 已登录：[发帖按钮]、[消息通知图标]、[用户头像(下拉菜单: 个人中心, 设置, 登出)]。
- **左侧主体 (70%)**：
  - **筛选栏**：最新 | 最热 | 精华 | 关注
  - **帖子列表**：
    - 每个列表项包含：标题、摘要、作者头像/昵称、发布时间、分类标签、互动数据(浏览/回复/点赞数)。
    - 列表项右侧或底部显示缩略图（如有）。
- **右侧侧边栏 (30%)**：
  - **用户信息卡片**（登录后）：头像、昵称、等级、获赞数、关注/粉丝数。
  - **公告栏**：站点公告。
  - **热门标签/话题**：Tag云或列表。
  - **活跃用户榜**：本周发帖最多或获赞最多的用户列表。

### 3.2 登录/注册页 (Login/Register)
**布局结构**：中心卡片式布局
- **背景**：简洁的纯色或模糊背景图。
- **中心卡片**：
  - **顶部**：Logo + 标题 ("欢迎回来" / "创建账号")。
  - **表单区域**：
    - 账号输入框 (icon + placeholder)。
    - 密码输入框 (icon + placeholder + 显示/隐藏切换)。
    - (注册页) 确认密码、邮箱验证码输入框。
  - **操作按钮**：
    - [登录/注册] 大按钮 (主色调)。
    - 辅助链接：忘记密码? | 没有账号?去注册。
  - **底部**：第三方登录入口 (微信/GitHub/Google)。

### 3.3 帖子详情页 (Post Detail)
**布局结构**：标准流式布局
- **面包屑导航**：首页 > 分类 > 正文。
- **楼主区域 (Header)**：
  - 标题 (H1)。
  - 元数据：发布时间、阅读量、来源。
  - 作者信息栏：头像、昵称、等级徽章、[关注]按钮。
- **正文区域**：
  - 富文本内容展示。
  - 图片画廊/附件下载区。
- **底部操作栏**：
  - [点赞] [收藏] [分享] [举报]。
- **评论区**：
  - **发表评论框**：富文本输入、表情包、[发送]按钮。
  - **评论列表**：
    - 楼层号 (#1, #2)。
    - 用户信息 + 评论内容。
    - 楼中楼回复列表 (折叠/展开)。
    - 操作：回复、点赞、举报。

### 3.4 发帖/编辑页 (Create/Edit Post)
**布局结构**：全宽工作台模式
- **顶部**：标题输入框 (大号字体)。
- **工具栏**：分类选择器、标签输入框。
- **编辑器主体**：
  - Markdown/富文本编辑器。
  - 工具栏：加粗、链接、代码块、图片上传、预览模式切换。
- **底部**：
  - 设置选项：仅通过验证的用户可见、禁止评论。
  - 操作按钮：[保存草稿] [发布帖子]。

### 3.5 个人中心 (User Profile)
**布局结构**：左侧菜单 + 右侧内容
- **头部**：个人封面图、大头像、昵称、签名、详细统计数据 (注册天数、积分)。
- **左侧菜单**：
  - 个人资料 (修改资料、账号安全)。
  - 我的内容 (帖子、回复)。
  - 我的收藏。
  - 消息中心 (系统通知、收到的回复)。
- **右侧内容区**：
  - 对应左侧菜单的列表展示。
  - 支持分页和按时间排序。

### 3.6 管理后台 (Admin Dashboard)
**布局结构**：侧边导航栏 + 顶部Header + 内容区域
- **侧边导航**：
  - 仪表盘 (概览)。
  - 用户管理 (列表、搜索、权限调整，超级管理员可修改管理员和版主权限)。
  - 内容管理 (回收站)。
  - 系统设置 (站点信息)。
- **仪表盘内容**：
  - 数据卡片：今日新增用户、今日发帖数。
  - 趋势图表：近7日流量趋势。
  - 快捷操作入口。
