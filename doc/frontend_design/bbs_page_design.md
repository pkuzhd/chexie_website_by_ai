# 论坛主页设计文档

## 1. 页面概述

本页面是论坛系统的核心讨论区页面，URL为 `/bbs`，是用户浏览和参与论坛讨论的主要入口。页面采用简洁清晰的布局，方便用户快速获取最新的讨论内容和参与互动。

## 2. 功能需求

基于参考论坛 `https://chexie.net/bbs` 的功能，论坛主页需实现以下功能：

- 显示论坛所有讨论版块列表，包含版块名称、描述和发帖统计
- 显示论坛热点内容，分为全局置顶帖子和热门帖子两类
- 显示帖子标题、作者、发布时间、回复数和浏览数等基本信息
- 支持帖子分类标识（如【实践部】、【文体部】、【公告】等部门/类型标识）
- 支持多种帖子类型（部门通知、活动公告、个人分享、旅行日志、讨论话题等）
- 支持用户点击进入帖子详情页
- 响应式设计，适配不同设备屏幕

## 3. 布局结构

页面采用清晰的双栏布局，同时展示讨论版块和论坛热点，主要包含以下几个部分：

### 3.1 顶部导航栏

- **左侧**：论坛Logo（如"CAPUBBS"）、首页按钮
- **右侧**：
  - 登录状态：用户头像、用户等级、个人中心按钮、退出登录按钮
  - 未登录状态：登录按钮、注册按钮

### 3.2 主体内容区

主体内容区分为两个主要部分：

#### 3.2.1 讨论版块
- **版块列表**：展示论坛中所有的讨论版块，每个版块包含：
  - 版块名称
  - 版块描述
  - 版块图标（可选）
  - 最新帖子信息（标题、作者、时间）
  - 今日发帖数/总发帖数

#### 3.2.2 论坛热点
- **全局置顶帖子**：显示带有"[置顶]"标识的重要帖子，位于热点区域最上方
- **热门帖子**：显示带有"[热门]"标识的高人气帖子，按热度排序
- **帖子信息**：每个帖子包含：
  - 帖子分类标识（如【实践部】、【文体部】等，使用方括号标识）
  - 帖子类型标识（[置顶]/[热门]）
  - 帖子标题（可点击进入详情页）
  - 作者用户名
  - 发布时间（精确到秒）
  - 回复数/浏览数

### 3.3 底部信息栏

- 论坛版权信息
- 联系方式
- 友情链接

### 3.4 可选侧边栏

- 在桌面端可选择性显示侧边栏，包含：
  - 论坛分类列表
  - 热门话题
  - 活跃用户
  - 论坛统计信息

## 4. 交互设计

### 4.1 讨论版块交互

- **鼠标悬停**：版块行背景色轻微变化，提供视觉反馈
- **点击版块名称**：跳转到对应版块的帖子列表页面，URL格式为`/bbs/section/:id`

### 4.2 帖子列表交互

- **鼠标悬停**：帖子行背景色轻微变化，提供视觉反馈
- **点击标题**：跳转到帖子详情页，URL格式为`/bbs/post/:id`
- **区分帖子类型**：通过颜色和标签直观区分全局置顶帖子和热门帖子

### 4.3 导航交互

- **顶部导航**：点击首页按钮返回网站首页
- **用户头像**：点击头像查看用户信息
- **个人中心**：点击进入用户个人中心页面
- **退出登录**：点击退出当前登录状态

### 4.4 响应式交互

- **桌面端**：双栏布局，鼠标悬停效果
- **移动端**：单栏布局，触摸友好的按钮尺寸和间距

## 6. 响应式设计

### 6.1 桌面端 (≥ 1024px)

- 布局：顶部导航栏 + 主体内容区（双栏布局：讨论版块 + 论坛热点）
- 讨论版块和论坛热点并列展示，提供完整的论坛概览
- 帖子列表以清晰的卡片形式展示完整信息

### 6.2 平板端 (768px - 1023px)

- 主体内容区转为单栏布局，讨论版块在上，论坛热点在下
- 导航栏元素适当简化，保持核心功能
- 帖子列表保持清晰的信息层级

### 6.3 移动端 (< 768px)

- 导航栏转为垂直布局，优化移动端触摸体验
- 主体内容区保持单栏布局
- 简化帖子信息展示，突出核心内容
- 优化按钮尺寸和间距，确保良好的触摸交互

## 7. 前端技术实现建议

### 7.1 框架与技术选型

- 使用 Vue 3 + Composition API 实现组件化开发
- 使用 Vue Router 进行路由管理和导航控制
- 使用 CSS 预处理器（如 SCSS）或 UI 框架（如 Element Plus）实现样式
- 使用 LocalStorage 存储用户偏好设置

### 7.2 性能优化策略

- 实现帖子列表的按需渲染
- 对静态资源进行优化和压缩
- 使用虚拟滚动技术处理大量帖子数据

### 7.3 无障碍与用户体验

- 确保页面元素具有适当的语义化标签
- 支持键盘导航操作
- 提供足够的颜色对比度
- 实现平滑的页面过渡效果
- 添加适当的加载状态提示

## 8. 设计参考

本设计参考了 `https://chexie.net/bbs` 的论坛功能和布局，主要特点包括：

- 简洁的单栏布局，专注于帖子内容展示
- 按时间倒序排列的最新讨论列表
- 帖子标题前使用方括号明确标识部门或活动分类（如【实践部】、【文体部】等）
- 多样化的帖子类型：部门通知、活动公告、个人分享、旅行日志、讨论话题等
- 简洁的帖子元信息展示（作者、精确时间）
- 便于用户快速浏览和点击进入详情页
