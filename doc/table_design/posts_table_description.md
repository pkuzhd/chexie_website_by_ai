# Posts表结构介绍文档

## 1. 表结构概览

Posts表是论坛系统的帖子内容表，用于存储论坛所有帖子（主题帖和回复帖）的详细内容、元数据和状态信息。该表设计用于支持帖子内容展示、回复管理、格式控制和用户交互等功能。

## 3. 字段详细说明

### 3.1 核心标识字段

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| bid    | 板块ID，用于关联BoardInfo表，标识帖子所属板块                          |
| tid    | 主题ID，用于关联Threads表，标识帖子所属主题                              |
| pid    | 帖子ID，用于标识主题内的帖子顺序，支持嵌套回复功能                        |
| fid    | 全局帖子ID，主键，自增，用于唯一标识论坛内的所有帖子                      |

### 3.2 内容与标题信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| title  | 帖子标题，主题帖使用与threads表相同的标题，回复帖可使用引用标题            |
| text   | 帖子内容，存储帖子的详细文本内容，支持HTML格式                          |
| ishtml | HTML标记，标识帖子内容是否包含HTML格式，用于前端渲染控制                  |
| attachs| 附件信息，存储帖子的附件数据，如图片、文件等                            |

### 3.3 作者与状态信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| author | 帖子作者，存储发布帖子的用户名称，关联UserInfo表                       |
| sig    | 签名标记，标识是否显示用户签名                                          |
| type   | 帖子类型，标识帖子的特殊类型（如公告、精华、置顶等）                    |
| lzl    | 楼中楼标记，标识是否支持楼中楼回复功能                                  |

### 3.4 时间与位置信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| replytime| 发布时间戳，记录帖子的发布时间（10位秒级时间戳）                      |
| updatetime| 更新时间戳，记录帖子的最后更新时间                                    |
| ip     | 发布IP地址，记录用户发布帖子时的IP地址                                  |

## 4. 表设计特点与使用建议

### 4.1 设计特点

1. **唯一标识**：使用自增fid作为全局唯一标识，支持跨板块的帖子管理
2. **关联关系**：通过bid、tid、pid字段与板块、主题和其他帖子建立关联
3. **内容支持**：使用longtext存储帖子内容，支持长篇帖子和复杂格式
4. **附件管理**：独立的attachs字段支持多种附件类型和格式
5. **时间追踪**：分别记录发布时间和更新时间，支持内容版本管理

### 4.2 使用建议

1. **内容处理**：注意对text字段的HTML内容进行安全过滤，防止XSS攻击
2. **性能优化**：对频繁查询的字段（如bid、tid、author、replytime）添加索引
3. **数据分区**：考虑按时间或板块对posts表进行分区，提高查询效率
4. **附件存储**：建议将大附件存储在文件系统中，仅在attachs字段存储文件路径
5. **内容缓存**：对热门帖子的内容进行缓存，减少数据库查询压力

## 5. 与其他表的关系

Posts表作为论坛系统的核心表之一，与其他表存在以下主要关系：

1. **与BoardInfo表**：多对一关系，通过bid字段关联，标识帖子所属板块
2. **与Threads表**：多对一关系，通过tid字段关联，标识帖子所属主题
3. **与UserInfo表**：多对一关系，通过author字段关联，标识帖子作者
4. **自关联**：通过pid字段实现帖子之间的回复关系，支持嵌套回复功能

## 6. 典型应用场景

1. **主题帖内容展示**：根据bid和tid查询主题帖的详细内容
2. **回复列表查询**：根据tid查询主题下的所有回复帖
3. **用户发帖统计**：根据author字段统计用户的发帖数量和内容
4. **时间线展示**：根据replytime字段按时间顺序展示帖子
5. **内容搜索**：对title和text字段进行全文搜索，查找相关内容
