# Threads表结构介绍文档

## 1. 表结构概览

Threads表是论坛系统的主题帖表，用于存储论坛所有主题帖的基本信息、统计数据和状态配置。该表设计用于支持主题帖管理、内容分类、排序展示和用户交互等功能。

## 2. 表结构详情

| 字段名     | 数据类型     | 空值允许 | 键约束   | 默认值 | 额外属性 |
|----------|--------------|----------|----------|--------|----------|
| bid      | tinyint      | NO       | PRIMARY  | NULL   |          |
| tid      | int          | NO       | PRIMARY  | NULL   |          |
| title    | text         | YES      |          | NULL   |          |
| author   | varchar(30)  | YES      | MUL      | NULL   |          |
| replyer  | varchar(30)  | YES      |          | NULL   |          |
| click    | int          | YES      |          | NULL   |          |
| reply    | int          | YES      |          | NULL   |          |
| guesture | tinyint      | YES      |          | NULL   |          |
| extr     | tinyint      | YES      | MUL      | NULL   |          |
| top      | tinyint      | YES      | MUL      | NULL   |          |
| locked   | tinyint      | YES      |          | NULL   |          |
| timestamp| bigint       | YES      | MUL      | NULL   |          |
| postdate | varchar(30)  | YES      | MUL      | NULL   |          |

## 3. 字段详细说明

### 3.1 核心标识字段

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| bid    | 板块ID，主键，用于关联BoardInfo表，标识主题帖所属板块                  |
| tid    | 主题ID，主键，用于唯一标识板块内的主题帖                              |
| title  | 主题标题，显示在主题列表和内容页面中                                    |

### 3.2 内容与作者信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| author | 主题作者，存储发布主题的用户名称，关联UserInfo表                       |
| replyer| 最后回复者，存储最后回复该主题的用户名称，关联UserInfo表               |

### 3.3 统计与状态信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| click  | 点击数，记录主题帖被查看的次数                                        |
| reply  | 回复数，记录主题帖收到的回复数量                                      |
| guesture| 表情状态，用于标识主题帖的特殊状态或标记                              |
| extr   | 扩展状态，用于特殊主题帖的标识和排序                                  |
| top    | 置顶状态，用于控制主题帖的置顶级别和显示顺序                            |
| locked | 锁定状态，0表示开放回复，1表示禁止回复                                |

### 3.4 时间信息

| 字段名 | 说明                                                                 |
|--------|----------------------------------------------------------------------|
| timestamp| 发布时间戳，记录主题帖的发布时间（10位秒级时间戳）                      |
| postdate| 发布日期，记录主题帖的发布日期（字符串格式）                          |

## 4. 表设计特点与使用建议

### 4.1 设计特点

1. **复合主键**：使用bid+tid作为复合主键，确保主题帖在板块内的唯一性
2. **状态多样性**：支持置顶、锁定、扩展等多种主题状态，满足不同管理需求
3. **性能优化**：关键字段（author、timestamp、top等）添加索引，提高查询效率
4. **统计功能**：内置点击数和回复数统计，支持主题热度排序

### 4.2 使用建议

1. **主题排序**：根据top、timestamp、reply等字段组合实现主题帖的智能排序
2. **状态管理**：合理使用locked和top字段控制主题帖的可访问性和重要性
3. **索引优化**：根据查询需求为title或其他频繁查询字段添加全文索引
4. **数据一致性**：确保bid在BoardInfo表中存在，author在UserInfo表中存在
5. **性能监控**：定期清理过期主题或优化热门主题的缓存策略

## 5. 与其他表的关系

Threads表作为论坛系统的核心表之一，与其他表存在以下主要关系：

1. **与BoardInfo表**：多对一关系，多个主题帖属于一个板块
2. **与Posts表**：一对多关系，一个主题帖可以包含多个回帖
3. **与UserInfo表**：多对多关系，通过author和replyer字段与用户表关联

## 6. 典型应用场景

1. **主题列表展示**：查询指定板块的主题帖列表，根据top和timestamp排序
2. **主题详情查询**：根据bid和tid查询特定主题帖的详细信息
3. **热门主题统计**：根据click或reply字段统计热门主题
4. **主题管理**：修改主题状态、标题、作者等信息
5. **搜索功能**：根据title字段搜索相关主题帖
